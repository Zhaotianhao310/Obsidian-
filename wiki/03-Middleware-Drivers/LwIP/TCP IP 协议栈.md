# TCP IP 协议栈

## 定义

TCP/IP 协议栈不是单一协议，而是一组网络协议的集合，包含 ARP、IP、ICMP、UDP、TCP、DNS、DHCP、HTTP、FTP、MQTT 等。

## 分层意义

- 将复杂网络通信拆成职责不同的层，降低整体理解和实现难度。
- 低层协议为上层协议提供服务，上层协议不必直接处理全部底层细节。
- 协议之间存在依赖关系，例如 TCP/UDP 依赖 IP，IP 又依赖链路层收发能力。

## 嵌入式关注点

- STM32 网络应用通常不直接手写完整协议栈，而是使用 [[LwIP]]。
- [[MAC 层与 PHY 层]]保证底层以太网帧和物理链路。
- [[LwIP]]负责在资源受限环境中提供 TCP/IP 协议能力。
- 应用侧通过 API 处理连接、收发、回调与错误事件。
