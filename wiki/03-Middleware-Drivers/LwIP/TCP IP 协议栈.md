# TCP IP 协议栈

## 概念

TCP/IP 不是单个协议，而是一组相互协作的网络协议。原素材列举的协议包括 ARP、IP、ICMP、UDP、TCP、DNS、DHCP、HTTP、FTP 和 MQTT。

## 分层作用

网络分层把复杂通信拆成若干职责明确的部分：低层协议为相邻的高层协议提供服务，高层协议不必直接处理全部底层细节。数据发送时逐层封装，接收时逐层解封装。

## STM32 关注范围

原素材建议嵌入式 STM32 学习时重点理解 TCP/IP 五层模型，并将实际协议实现交给 [[LwIP]]。底层还要区分：

- 链路层：以 MAC 地址识别网卡并组织以太网帧。
- 网络层：以 IP、ARP、ICMP 等协议完成寻址和网络互联。
- 传输层：由 TCP 或 UDP 为应用提供不同的传输语义。
- 应用层：由具体应用协议或自定义 TCP 数据格式承载业务。

## 与硬件的边界

[[MAC 层与 PHY 层]]解决以太网帧和物理链路问题；[[LwIP]]解决协议栈实现问题；二者都不等同于最终的 TCP 业务协议。
