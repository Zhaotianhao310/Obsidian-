# XPT2046 触摸采样与坐标校准

## 概念一句话精炼

XPT2046 通过切换四线电阻屏的激励方向并读取 12 bit ADC 得到原始 X/Y 值，再用多次采样、中值滤波、四角校准和线性映射转换为 ST7789 像素坐标；关联 [[XPT2046 EXTI 触摸中断]] 与 [[ST7789 窗口机制]]。

## 核心原理与图解

```mermaid
flowchart LR
    A[触摸点改变电阻分压] --> B[XPT2046 选择 X/Y 测量通道]
    B --> C[发送 8 bit 命令]
    C --> D[继续 16 个时钟读取 12 bit ADC]
    D --> E[同轴采样 5 次]
    E --> F[中值滤波]
    F --> G[四角标定范围]
    G --> H[线性映射与边界钳位]
    H --> I[ST7789 像素坐标]
```

> 图 1：XPT2046 输出的是与触摸位置相关的 ADC 原始值，稳定的屏幕坐标必须经过滤波和面板个体化校准。

### 命令字节与读数格式

| 命令 | 值 | 通道 | 关键位含义 | 用途 |
|---|---:|---|---|---|
| X 测量 | `0xD0` | `A2A1A0=101` | `S=1`、12 bit、SER、PD=00 | 读取 X 轴原始值 |
| Y 测量 | `0x90` | `A2A1A0=001` | `S=1`、12 bit、SER、PD=00 | 读取 Y 轴原始值 |
| Z1 | `0xB0` | `A2A1A0=011` | 压力测量通道 | 可用于压力计算 |
| Z2 | `0xC0` | `A2A1A0=100` | 压力测量通道 | 可用于压力计算 |

一次读取保持 CS 有效并提供 24 个时钟：前 8 个时钟发送命令，后 16 个时钟接收数据。第二个接收字节承载 `D11..D4`，第三个接收字节高 4 位承载 `D3..D0`。

## 关键实现与数据结构

```c
uint16_t adc = ((uint16_t)rx1 << 4) | (rx2 >> 4); // 拼出 12 bit

for (int i = 0; i < 5; ++i)
    samples[i] = XT2046_ReadAdc(cmd);             // 工程函数
sort(samples, 5);                                  // 伪代码：排序
adc = samples[2];                                  // 取中值抑制毛刺

px = (adc_x - X_MIN) * ST7789_WIDTH  / (X_MAX - X_MIN);
py = (adc_y - Y_MIN) * ST7789_HEIGHT / (Y_MAX - Y_MIN);
```

`XT2046_ReadAdc`、`sort` 和坐标映射封装属于工程实现或伪代码，不是官方 API。实际实现还应在映射前进行范围钳位，避免 ADC 越界或校准范围无效导致无符号整数下溢。

### 校准流程

1. 在屏幕四角依次按下，记录 X/Y 原始 ADC 值。
2. 将四角极值写入 `X_MIN/X_MAX/Y_MIN/Y_MAX` 类配置项。
3. 如果触摸方向与显示方向不一致，调整 `FLIP_X/FLIP_Y`。
4. 用中心点和边缘点复测，确认映射没有镜像、偏移或越界。

## 横向对比与关联

| 阶段 | 输入/输出 | 主要问题 | 处理方式 |
|---|---|---|---|
| ADC 原始采样 | SPI 命令 → 12 bit 原始值 | 噪声、抖动 | 同通道多次采样 |
| 中值滤波 | 多个原始值 → 稳定值 | 毛刺影响单点 | 取排序后的中值 |
| 线性映射 | 稳定 ADC → 像素坐标 | 面板个体差异 | 四角标定后插值 |
| 方向修正 | 像素坐标 → UI 坐标 | X/Y 镜像 | `FLIP_X/FLIP_Y` 与边界钳位 |
